LiveView Duo

Support

Last updated 26 October 2026

LiveView Duo turns a second iPhone into a camera monitor and remote control. One iPhone records; the other shows you the live image and drives the shoot.

This app needs two iPhones. With a single device you will only ever reach the pairing screen. That is the product working as designed, not a broken install.

Getting started

  1. Install on two iPhones running iOS 17 or later.
  2. Open the app on both and allow camera, microphone and local network access.
  3. On the first iPhone, choose Camera. A six-digit pairing code appears on screen.
  4. On the second, choose Monitor, pick the first iPhone from the list and type that code.

You only type the code once. From then on the two iPhones recognise each other and connect on their own.

If they can't find each other

Turn Wi-Fi on — even with no network to join

The two iPhones talk to each other directly, so you do not need a router, a hotspot or any internet connection. But that direct link travels over the Wi-Fi radio, so Wi-Fi has to be switched on in both devices. This is the most common reason a pair stops seeing each other outdoors.

Check the local network permission

iOS asks for it once, and if you decline there is no way for the app to ask again. Go to Settings › LiveView Duo › Local Network and turn it on, on both iPhones.

Both apps have to be open

iOS suspends apps in the background, so the camera stops being visible on the network while the app is not on screen. Bring it back to the front and the link re-establishes on its own.

The monitor asks for the code again

That means the camera generated a new code. Tapping the code on the camera's screen regenerates it, which unpairs every monitor on purpose — it is also how you revoke access. Type the new code once and you are paired again.

Where your video goes

Nowhere. Video and audio travel directly between your two iPhones, the connection is encrypted, and recordings are saved to the photo library of the iPhone that was filming. There is no account, no server and no analytics. The full details are in the privacy policy.
